# Game Review

The built files of Game Review, a personal chess game reviewer, served by GitHub Pages.
Open the site in Safari on a phone and choose Share → Add to Home Screen.

Everything runs on your device; the site only serves these files.

Includes Stockfish 19 (GNU GPL v3; see licenses/stockfish-GPL-3.0.txt). Source:
https://github.com/official-stockfish/Stockfish and https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.0.
Chess pieces by Colin M.L. Burnett (CC BY-SA 3.0). Opening names from lichess-org/chess-openings (CC0).
